# OutbreakIQ demo video outline (2–3 minutes)

1. **Opening (15 seconds):** Introduce OutbreakIQ and the problem of exploring large public-health reporting datasets.
2. **Data provenance (25 seconds):** Show the demo-data notice, then load CDC NNDSS data if the live connection is working. Explain that weekly reports are provisional. If live data are unavailable, explicitly keep the synthetic demo label visible.
3. **Dashboard (30 seconds):** Demonstrate condition, reporting-area, and time-window filters; show the trend chart.
4. **Map (25 seconds):** Select a reporting area from the map and show how the dashboard filters.
5. **Anomaly screening (35 seconds):** Open a flagged observation and explain its reported count, rolling baseline, and z-score. Emphasize that it is not a confirmed outbreak.
6. **Assistant (25 seconds):** Ask the assistant to explain the strongest signal and show the limitations in its answer.
7. **Close (15 seconds):** Summarize the technical components and explain how the project supports exploration, not diagnosis or official public-health decisions.
